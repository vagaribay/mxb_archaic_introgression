# data_processing/archaic_genomes

Scripts used to prepare the four high-coverage archaic genomes (Altai Neanderthal, Vindija Neanderthal, Chagyrskaya-Phalanx Neanderthal and Altai Denisovan), run on the Brown University Oscar cluster (SLURM). Paths at the top of each script are placeholders.

We used the hg38-liftovered archaic genomes generated by Laurits Skov (TODO: link). High-confidence masks were made by lifting over the FilterBed files from http://ftp.eva.mpg.de/neandertal/ to GRCh38 with CrossMap, then standardized, sorted and applied to the four archaic genomes.

| Step | Script | Run as |
|---|---|---|
| 1 | `01.LiftOverFilterBed.sh` | `sbatch --array=1-22 01.LiftOverFilterBed.sh <archaic>` |
| 2 | `02.RenameSortMasks.sh` | `sbatch 02.RenameSortMasks.sh` |
| 3 | `03.ApplyMasks.sh` | `sbatch --array=1-22 03.ApplyMasks.sh <archaic>` |
| 4 | `04.MergeArchaics.sh` | `sbatch --array=1-22 04.MergeArchaics.sh` |

`<archaic>`: `AltaiNeandertal`, `Vindija33.19`, `Denisova` or `Chagyrskaya-Phalanx`

Final output: `SkovFiles/individuals_highcov.QC.chr{1..22}.vcf.gz`
